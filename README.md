# StatChem: эпикриз → JSON

MVP для медицинского хакатона Yandex Cloud. Приложение извлекает 50 признаков из синтетических кардиологических выписок, проверяет основания извлечения и создаёт JSON с девятью группами в точности по шаблону участника.

Реализованы пакетный CLI, локальная анонимизация Natasha + правила, извлечение правилами, адаптер Yandex API со структурированным ответом, проверка цитат и контекста, Pydantic + независимая JSON Schema, отчёты и интерфейс Streamlit. Входные документы сохраняются в исходном каталоге без изменений.

## Быстрый запуск

Python 3.11–3.13; рекомендуем Python 3.12. Для Natasha достаточно CPU. Внешний API нужен только режиму `yandex`. Все команды выполняются из корня проекта.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-build-isolation --no-deps -e .
.\.venv\Scripts\python.exe -m statchem run --mode rules
.\.venv\Scripts\python.exe -m statchem validate
.\.venv\Scripts\python.exe -m streamlit run app.py --browser.gatherUsageStats=false
```

Linux / сервер Yandex:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-build-isolation --no-deps -e .
.venv/bin/python -m statchem run --mode rules
.venv/bin/python -m streamlit run app.py --server.address=0.0.0.0 --browser.gatherUsageStats=false
```

Интерфейс доступен на `http://localhost:8501`. Выберите эпикриз, нажмите «Извлечь признаки»; раскройте группу, чтобы увидеть значения, цитаты и координаты. Повторные лабораторные измерения показаны отдельно. Можно скачать JSON или ZIP с подтверждениями и обезличенным текстом.

В текущей рабочей папке окружение `.venv` уже подготовлено, включая pip. На обычном Python достаточно команд выше.

## Подключение Yandex

```powershell
Copy-Item config/.env.example config/.env
```

Заполните `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в `config/.env` на своей машине/сервере. Ключ не включается в Git, результаты или сообщения об ошибках. `YANDEX_MODEL=yandexgpt/5.1` — явно заданная версия из плана; доступность этой версии в вашем каталоге нужно проверить. При необходимости установите доступный идентификатор, сохранив его в конфигурации эксперимента.

```powershell
.\.venv\Scripts\python.exe -m statchem check-api
.\.venv\Scripts\python.exe -m statchem run --mode yandex --limit 2 --output result-yandex --reports reports-yandex
.\.venv\Scripts\python.exe -m statchem run --mode yandex --output result --reports reports-yandex
```

Адаптер использует `https://ai.api.cloud.yandex.net/v1`, заголовок проекта и JSON Schema, согласно [официальному примеру Yandex](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-structured). Нужны права сервисного аккаунта `ai.languageModels.user` и область ключа `yc.ai.foundationModels.execute`. На эпикриз выполняется один запрос; SDK повторяет временные ошибки до двух раз. Таймаут и максимальная длина ответа задаются в `.env`.

В облачном режиме отсутствие ключа, отключённая NER или остаточные идентификаторы блокируют отправку. Ошибка API не подменяется успешным результатом локальных правил. Живой вызов Yandex пока не выполнен: настройки пользователь добавит позже. Формат запросов и обработка ответов проверены через имитацию HTTP.

## Вход и выход

- Вход: каталог `.md` в UTF-8 / UTF-8 BOM; пустые и некорректно закодированные файлы получают статус ошибки.
- `result/train-0001.json`: только обязательные девять групп и 50 строковых полей, без служебных ключей.
- `reports/evidence/train-0001.json`: факты, точные цитаты, координаты, раздел, контекст, источник, предупреждения и повторные анализы.
- `reports/anonymized/train-0001.md`: обезличенная рабочая копия, к которой относятся цитаты.
- `reports/run.json`: статусы всех документов, время, число подтверждённых полей, ошибки и дубликаты.
- `config/output.schema.json`: независимая схема результата.

Для имён официального корпуса `train-NNNN` / `test-NNNN` / `doc-NNNN` / `synthetic-NNNN` сохраняется базовое имя. Произвольные имена файлов заменяются хешированным идентификатором, чтобы случайно не экспортировать ФИО из имени файла. Исходные значения идентификаторов не сохраняются в таблице масок. Позиции — индексы Unicode-символов, с нуля, правая граница не включается. Маски имеют ту же длину, поэтому координаты совпадают с оригиналом.

```powershell
.\.venv\Scripts\python.exe -m statchem run --input participant-kit-realistic-v2-100/documents --output result --reports reports --mode rules
.\.venv\Scripts\python.exe -m statchem schema
.\.venv\Scripts\python.exe -m statchem validate --directory result
```

Коды завершения: `0` — пакет обработан, `1` — есть ошибки документов, `2` — ошибка конфигурации/запуска. Статус `review` означает, что JSON создан, но есть предупреждения; он не считается ошибкой обработки. Значения по правилу пропуска не получают вымышленных цитат. Неудачная повторная обработка удаляет прежний результат этого документа, чтобы он не выглядел результатом нового успешного запуска.

## Правила и ограничения

Полный справочник: `src/statchem/data/fields.json`; решения о нормализации: [docs/decisions.md](docs/decisions.md).

Лаборатория выбирается из первичных разделов, контрольные результаты сохраняются отдельно; осмотр и ЭКГ разделены. ИМТ не вычисляется. Бинарные поля получают `0` при отсутствии упоминания по правилу кейса. Курение — текст. Терапия — активные назначения при выписке с дозой и режимом. Кандидат модели принимается только после проверки цитаты, раздела, контекста и подтверждения значения. При конфликте сохраняется результат правил, а документ получает статус `review`.

Правила поддерживают варианты заголовков корпуса, Markdown-заголовки и простые таблицы. Свободные формулировки, сложные сочетания отрицаний, необычные лекарственные названия и исторические эпизоды могут потребовать доработки. Наличие цитаты подтверждает происхождение, но не гарантирует смысловую правильность.

Используйте только синтетические документы. Условия кейса запрещают реальные медицинские документы; прототип не предназначен для диагностики или принятия клинических решений. Удаление прямых идентификаторов не является заявлением о полной анонимности или юридической готовности. Даты медицинского эпизода сохранены по условиям кейса. Natasha обучена на новостном тексте; закрытый список медицинских слов защищает заголовки от ложного маскирования, а остаточная проверка блокирует сомнительные случаи.

## Тесты и оценка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m statchem evaluate --gold tests/reference --predictions result --report reports/developer-check.json
```

Тесты проверяют ловушки кейса, отрицания, границы 49/50/89/90%, анонимизацию, цитаты, ошибки пакета, HTTP-адаптер и интерфейс. Два эталона в `tests/reference` составлены по прочитанным эпикризам для технической проверки разработчика; они не являются разметкой организаторов или медицинского эксперта. Для независимой оценки подготовьте собственный проверенный каталог JSON и передайте его через `--gold`.

Корпус из 100 документов обработан локальными правилами с Natasha. Фактические показатели последнего запуска находятся в `reports/run.json`, описание проверки — в [docs/quality.md](docs/quality.md). Валидность структуры и скорость отделены от точности. Точность на скрытых 1000 документах не измерена. Список 20 документов в `config/validation-split.json` предназначен для последующей независимой проверки после фиксации версии; он не объявлен незатронутой отложенной выборкой текущей разработки.

## Docker

```bash
docker compose up --build
docker compose run --rm app python -m statchem run --mode rules
docker compose run --rm app python -m statchem run --mode yandex
```

Контейнер содержит синтетический корпус; результаты и отчёты сохраняются через bind mounts. Секреты поступают из необязательного `config/.env`, который не копируется в образ. Для собственного корпуса добавьте том с `.md` и задайте `--input`. Версии Python, прямых и транзитивных зависимостей закреплены. На текущей машине Docker daemon не запущен, поэтому сборка образа не проверена; запуск Python и Streamlit проверен локально.

```text
app.py             интерфейс Streamlit
requirements.lock  закреплённые зависимости

```
