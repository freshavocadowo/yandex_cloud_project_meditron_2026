# StatChem: эпикриз → JSON с 50 признаками

Прототип медицинского хакатона: читает синтетические эпикризы, обезличивает текст, извлекает признаки и показывает подтверждающие цитаты. Результат содержит 50 строковых полей в 9 группах. Есть два режима: локальные правила и правила с YandexGPT.

**Сначала запустите локальный режим по инструкции ниже. Для него облако и API-ключ не нужны.** Затем настройте YandexGPT по [пошаговой инструкции Yandex Cloud](docs/YANDEX_CLOUD_SETUP.md). Для обращения к YandexGPT отдельная виртуальная машина или GPU не требуется.

## 1. Что открыть в VS Code

1. Откройте VS Code.
2. Выберите **File → Open Folder / Файл → Открыть папку**.
3. Выберите папку `D:\JSON_statchem`, целиком, а не отдельный файл.
4. Слева должны появиться `app.py`, `pyproject.toml`, папки `src`, `config` и `participant-kit-realistic-v2-100`.
5. Откройте **Terminal → New Terminal / Терминал → Создать терминал**. Внизу появится окно PowerShell.

Все команды ниже вводите в этот терминал, по одной строке. После каждой нажимайте Enter и дожидайтесь окончания. Не вставляйте обозначения блока ``` в терминал. Кнопка «Run Python File» для запуска этого интерфейса не нужна.

```powershell
cd D:\JSON_statchem
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m statchem --help
```

Если появились версия Python и список команд — переходите к разделу 3. В этой рабочей папке окружение уже подготовлено. Активировать его не нужно: мы явно указываем путь к его Python.

## 2. Установка на другом компьютере или без .venv

Установите Python 3.12, затем перезапустите VS Code. Проект поддерживает Python 3.11–3.13. Выполните из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-build-isolation --no-deps -e .
```

Для подсказок редактора нажмите **Ctrl+Shift+P → Python: Select Interpreter**, выберите `.venv\Scripts\python.exe`. Если этой команды нет, установите расширение Python от Microsoft в VS Code. Сам запуск из терминала работает без выбора интерпретатора в редакторе.

## 3. Увидеть результат в браузере — без облака

В терминале выполните:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address=127.0.0.1 --browser.gatherUsageStats=false
```

Терминал останется занят — это нормально: в нём работает приложение. Откройте в браузере **http://127.0.0.1:8501/**. Если страница уже открыта, обновите её.

1. Слева выберите **«Локальные правила»**.
2. Оставьте включённым **«Локальное распознавание имён (Natasha)»**.
3. Выберите первый документ из корпуса.
4. Нажмите **«Извлечь признаки»** и дождитесь результата.
5. Слева появится обезличенный текст, справа — значения и цитаты. Откройте вкладку **JSON**, чтобы увидеть итоговую структуру.
6. Нажмите **«Скачать JSON»** или **«Скачать JSON, цитаты и текст»**. Файл попадёт в папку загрузок браузера.

Предупреждения означают, что отдельные поля требуют проверки. Приложение не должно выдумывать значение, которого нет в тексте. Обозначение пропуска определяется контрактом данных. Интерфейс сохраняет скачанные файлы через браузер; для записи всей партии в папку проекта используйте следующую команду.

Чтобы остановить приложение, нажмите **Ctrl+C** в его терминале. Чтобы выполнять другие команды, пока интерфейс открыт, создайте второй терминал кнопкой **+**.

## 4. Сохранить JSON в папку проекта

Пробный запуск на двух документах:

```powershell
.\.venv\Scripts\python.exe -m statchem run --mode rules --limit 2 --output result-demo --reports reports-demo
.\.venv\Scripts\python.exe -m statchem validate --directory result-demo
```

Слева в VS Code появятся папки `result-demo` и `reports-demo`. В первой — итоговые JSON, во второй — цитаты, обезличенные тексты и отчёт запуска. Если папки не появились сразу, обновите проводник VS Code.

Обработка всего корпуса и проверка структуры:

```powershell
.\.venv\Scripts\python.exe -m statchem run --mode rules
.\.venv\Scripts\python.exe -m statchem validate
```

По умолчанию читается `participant-kit-realistic-v2-100/documents`, результат записывается в `result`, отчёты — в `reports`. Повторный запуск обновляет файлы с теми же именами. Для отдельного эксперимента задавайте отдельные `--output` и `--reports`.

## 5. Подключить YandexGPT

На сайте Yandex Cloud создайте сервисный аккаунт, назначьте ему роль `ai.languageModels.user` на ваш каталог и создайте API-ключ с областью действия `yc.ai.foundationModels.execute`. Все кнопки и поля описаны в [инструкции настройки](docs/YANDEX_CLOUD_SETUP.md).

В VS Code откройте **`config/.env`**. В текущей рабочей папке он подготовлен с вашим каталогом и пустым ключом. На другой копии проекта сначала скопируйте `config/.env.example` в `config/.env`. Не заменяйте уже заполненный файл.

```dotenv
YANDEX_API_KEY=вставьте_секретную_часть_API_ключа
YANDEX_FOLDER_ID=b1g0ts1csga0d48lf8iv
YANDEX_MODEL=yandexgpt-5.1
STATCHEM_TIMEOUT_SECONDS=90
STATCHEM_MAX_TOKENS=12000
STATCHEM_USE_NER=true
```

После знака `=` в первой строке нужен **секрет API-ключа**, а не его идентификатор, пароль входа или текст `Bearer`. Сохраните файл **Ctrl+S**. `config/.env` исключён из Git; не добавляйте его принудительно и не публикуйте скриншоты с ключом.

Идентификатор модели `yandexgpt-5.1` указан в [официальном списке моделей](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models). Приложение само собирает адрес `gpt://<каталог>/yandexgpt-5.1`.

Сначала проверьте доступ коротким платным запросом без эпикризов:

```powershell
.\.venv\Scripts\python.exe -m statchem check-api
```

Ожидаемый ответ: **«Yandex API и структурированный ответ доступны.»** Только после этого обработайте один документ:

```powershell
.\.venv\Scripts\python.exe -m statchem run --mode yandex --limit 1 --output result-yandex --reports reports-yandex
.\.venv\Scripts\python.exe -m statchem validate --directory result-yandex
```

Для работы через браузер перезапустите Streamlit после настройки `.env`, выберите **«Правила + YandexGPT»** и нажмите **«Извлечь признаки»**. Каждый такой запуск вызывает облачный API. Не запускайте сразу весь корпус, пока не проверили один документ и расходы.

## 6. Если не получается

| Что видите | Что сделать |
|---|---|
| Не найден `.venv\Scripts\python.exe` | Убедитесь, что терминал находится в папке проекта; выполните установку из раздела 2. |
| `No module named statchem` | Выполните команду `pip install --no-build-isolation --no-deps -e .` с Python из `.venv`, как в разделе 2. |
| `No module named streamlit` | Установите `requirements.lock` с Python из `.venv`. |
| Порт 8501 занят | Возможно, приложение уже запущено: откройте его страницу. Для второго экземпляра добавьте к команде `--server.port=8502` и откройте порт 8502. |
| Браузер пишет, что соединение невозможно | Проверьте, что терминал Streamlit открыт и в нём нет ошибки. |
| API не проверен / `ValueError` | Проверьте заполнение ключа и каталога, сохранение `.env`, значение `STATCHEM_USE_NER=true`. |
| `AuthenticationError` / `PermissionDeniedError` | Проверьте секрет ключа, срок действия, область действия и роль сервисного аккаунта. |
| `BadRequestError` / `NotFoundError` | Проверьте каталог, название модели и её доступность; сверяйтесь с актуальным списком моделей. |
| `RateLimitError` / `APITimeoutError` | Проверьте квоты и доступность сервиса; повторите позже. |

Если нужна помощь, присылайте название ошибки и команду, **без ключей и паролей**. Облачные ошибки намеренно выводятся без полного ответа провайдера.

## 7. Что в проекте уже есть

- `app.py` — интерфейс Streamlit.
- `src/statchem/` — обезличивание, правила, клиент YandexGPT, проверка структуры и цитат, команды обработки.
- `config/.env.example` — шаблон настроек; `config/.env` — ваши локальные настройки.
- `config/output.schema.json` — JSON Schema результата.
- `participant-kit-realistic-v2-100/documents/` — синтетические входные документы.
- `result/` и `reports/` — результаты пакетного запуска.
- `tests/` — автоматические проверки.

[PLAN.md](docs/PLAN.md) описывает план развития с дополнительными компонентами. GPU, vLLM, FastAPI и PostgreSQL из этого плана не нужны для текущего MVP. Команды вида `python -m app.batch` не являются командами текущей реализации; используйте `python -m statchem`.

## 8. Проверки и ограничения

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Локальный корпус ранее обработан: 100 JSON прошли структурную проверку, ошибок обработки нет. Структурная проверка не доказывает медицинскую точность. Предупреждения и неподтверждённые поля требуют просмотра. Используйте синтетические документы; это исследовательский прототип.

Настоящий запрос YandexGPT требует вашего API-ключа. До его добавления облачная интеграция проверена только автоматическими тестами с подменённым клиентом. Подробности: [качество](docs/quality.md), [решения](docs/decisions.md), [сценарий демонстрации](docs/demo.md).

## 9. Docker — необязательный вариант

Для первого запуска используйте раздел 3. Если установлен и запущен Docker Desktop, из папки проекта:

```powershell
docker compose up --build
```

Для остановки — Ctrl+C, затем `docker compose down`. Конфигурация Docker подготовлена, но сборка и запуск контейнера в этой среде не проверены.
