`review` возникает из-за качественного описания «гемодинамически значимого стеноза нет»: текст не содержит процента для шкалы 0/1/2. Значение не угадывается; требуется согласовать кодирование с наставником. Предупреждения не мешают созданию структурно валидного результата.

Два эталона подготовлены по текстам `train-0001` и `train-0002` для технической регрессии. Это не независимая медицинская разметка. Их 100 совпавших полей нельзя переносить на весь корпус или скрытые 1000 документов. Часть полей в эталонах — значения по правилу отсутствия.

Проверка анонимизации покрывает тестовые имена, дату рождения, возраст, номер истории, телефон, email и адрес; отдельный тест проверяет имя без метки. Аудит корпуса дополнительно проверяет координаты и остаточные шаблоны идентификаторов. Полная полнота распознавания неизвестна: её должен измерить человек на отдельно размеченных идентификаторах.

Метрика `quoted_fields` оценивает наличие основания, а не точность. Для всех цитат проверены непрерывный фрагмент и индексы в обезличенной копии. Pydantic и JSON Schema проверены отдельно. Независимого медицинского эксперта и размеченной контрольной выборки в текущей работе нет.

Сравнить группы и отдельные поля через `statchem evaluate`. Сохранить время и идентификатор модели в отчётах каждого запуска.
