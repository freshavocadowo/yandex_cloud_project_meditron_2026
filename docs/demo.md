# Сценарий демонстрации

1. Откройте Streamlit, выберите `train-0001`, нажмите «Извлечь признаки».
2. Покажите замаскированное имя, дату рождения и номер истории. Даты госпитализации сохранены.
3. Раскройте «осмотр при поступлении» и «ЭКГ»: пульс 92 и ЧСС ЭКГ 84 относятся к разным источникам.
4. Раскройте лабораторию: креатинин 99. В списке лабораторных наблюдений виден контроль 103, не выбранный для JSON.
5. Покажите КАГ R и отсутствие ложного статуса курения из рекомендации «курение исключить».
6. Переключитесь на `train-0002`: ХСН 2А, ФК 2 сохранена несмотря на отсутствие новых признаков в динамике; КАГ N.
7. Скачайте JSON и ZIP с цитатами. Покажите пакетные результаты и `reports/run.json`.
8. После добавления ключа выполните `check-api`, затем `run --mode yandex --limit 2` с отдельными каталогами результатов. Покажите разницу результатов и предупреждения, если они появились.

Технические факты для защиты: 9 обязательных групп, 50 строковых полей, двойная валидация, один запрос на обезличенный эпикриз, локальные правила и NER, проверка цитат и источников, изоляция ошибок документов. Фактическую скорость берите из свежего отчёта. Точность на медицински проверенной выборке и скрытом наборе пока не измерена.
