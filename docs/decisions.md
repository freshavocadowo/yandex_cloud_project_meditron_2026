# Решения MVP

Основания: шаблон участника, PDF кейса и расширенный DOCX `Кейс_Яндекс.Облако_в2.docx` из пакета. DOCX содержит определения всех полей, которых нет в кратком PDF.

| Вопрос | Принятое правило |
| --- | --- |
| Цитаты | Отдельный sidecar `reports/evidence`; структура `result` неизменна. Формат сдачи цитат согласовать с наставником. |
| Бинарные поля | `art_hyper`, `atr_fibril`, `copd`, `dm`, `tlt`, `ecg_avb`, `ecg_elevation`. Отсутствие упоминания → `0`, с явным основанием `coding_default`. |
| Другие пропуски | Обычные значения → `не указано`; локализация → `N`; тип ОКС → `NA`; факт КАГ → `N`. |
| Курение | Текстовый статус: «Курит», «Не курит», «Бросил курить». Рекомендация не является фактом. |
| Killip | Римские I/II/III/IV → строки 1/2/3/4; без вычислений по осмотру. |
| Тип ОКС | По явно указанному типу или формулировке диагноза о подъёме ST. Не выводится из кода МКБ или только ЭКГ. |
| ХСН, ХБП | Текст со стадией/ФК. Позднее отсутствие новых признаков не отменяет диагноз. |
| Лаборатория | Первое записанное первичное измерение текущего эпизода. Контроль/повтор/анамнез исключаются из выбора. Несколько наблюдений сохраняются в отчёте. |
| Терапия | Активный список при выписке; название, доза, режим остаются текстом с единицами, как в примерах DOCX. Этот период согласовать с наставником. |
| Эхо | `echo_lvd` = КДР ЛЖ, `echo_lvd_2` = ЛП; регургитация и зоны сохраняются точным фрагментом. |
| Рентген | `rg_pc` заполняется положительным описанием застоя/отёка; явное отрицание не создаёт положительный факт. |
| КАГ | Дата и сосуды заполняются только при `Y`; `R` требует явного отказа. Стентирование не кодирует тромболизис. |
| Стеноз | По числу: <50 → 0, 50–89 → 1, >=90/окклюзия → 2. «Без стеноза» → 0. |
| «Гемодинамически значимого стеноза нет» | Процент не указан; оставляем `не указано` и предупреждение `qualitative_stenosis_needs_review`. Привязку к категории 0 нужно подтвердить у наставника. |
| Конфликт модели и правил | Значение правила сохраняется, документ → `review`; специалист проверяет исходную цитату. |
| Исходные координаты | Текст не переписывается; заменяется каждый символ идентификатора, кроме переносов строки. Маски сохраняют длину. |

Правила не являются полной медицинской онтологией. Сложные отрицания и альтернативные формулировки требуют независимой разметки и проверки. Нельзя называть каждый созданный JSON клинически корректным только по результату валидации схемы.
